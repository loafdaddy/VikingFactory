# Branding

`vikingfactory-logo.png` is the project lockup: timber and iron gears behind the words Viking Factory. It is 1024×682. Use it wide, and do not squash it.

The original art sits on a black plate. This file keeps that artwork and clears only the background connected to the image border, so the mark can sit on a light or dark GitHub page. Dark metal inside the gears is left alone.

`packaging/icon.png` is a separate flat 256×256 mark for a future Thunderstore package. It is not this lockup.
